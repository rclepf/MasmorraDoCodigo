# Masmorra do Código

Aulas guiadas de codificação de jogos 3D em Unity e C# — UC Codificação de Sistemas de Jogos Digitais.

- `index.html`: mapa dos 12 módulos
- `modulo-01.html`: Pré-produção e ambiente
- `Dungeon3D_Kit.zip`: kit de modelos 3D (OBJ/MTL, CC0); `kit/gen_kit.py` é o gerador
- `atividades/`: atividades práticas em PDF

Publicação: Settings > Pages > Deploy from a branch > `main` / root.
