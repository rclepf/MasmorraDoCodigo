Ligação com a UC anterior

Na UC anterior você planejou cenas e personagens com intenção: o esqueleto guarda a sala do tesouro, o slime vive no corredor úmido. Agora essa intenção vira regra. Um bom inimigo não é só um modelo animado; é um modelo que toma decisões que o jogador consegue ler e prever.

Dica de produção. Desenhe no papel, antes de programar, o que seu monstro faz quando está calmo, quando vê o herói e quando perde o herói de vista. Se você não consegue explicar em três frases, o código também não vai ficar claro.

Decisões como árvore

Uma árvore de decisão é uma sequência de perguntas de sim ou não que termina em uma ação. Ela é a forma mais simples de IA e resolve muito do que um jogo precisa:

PerguntaSe simSe não
O herói está no alcance de ataque?Atacarpróxima pergunta
O herói está no campo de visão e sem parede no caminho?Perseguirpróxima pergunta
Perdi o herói de vista há mais de 3 segundos?Voltar ao postoContinuar a patrulha

A ordem das perguntas é uma decisão de design: colocar o ataque primeiro faz o inimigo ser agressivo; colocar a visão primeiro o faz cauteloso. Mudar a ordem muda a personalidade do monstro sem mudar nenhum modelo.

Máquina de estados finitos

A árvore diz o que decidir; a máquina de estados (FSM, de finite state machine) guarda em que situação o inimigo está. Em cada instante ele está em um só estado e as transições entre estados seguem as regras da árvore.

Em C#, o jeito mais direto é um enum com os estados e um switch no Update. Cada estado vira um método pequeno:

InimigoIA.cs 
using UnityEngine;

public class InimigoIA : MonoBehaviour
{
    private enum Estado { Patrulha, Perseguir, Atacar }

    [Header("Alvo e percepção")]
    [SerializeField] private Transform alvo;
    [SerializeField] private float alcanceVisao = 8f;
    [SerializeField, Range(10f, 180f)] private float anguloVisao = 110f;
    [SerializeField] private float alcanceAtaque = 1.5f;
    [SerializeField] private int dano = 1;
    [SerializeField] private float intervaloAtaque = 1f;
    [SerializeField] private LayerMask obstaculos;

    [Header("Movimento")]
    [SerializeField] private Transform[] pontosDePatrulha;
    [SerializeField] private float velocidadePatrulha = 1.5f;
    [SerializeField] private float velocidadePerseguicao = 3.5f;
    [SerializeField] private float tempoParaDesistir = 3f;

    private Estado estado = Estado.Patrulha;
    private int pontoAtual;
    private float tempoSemVer;
    private float proximoAtaque;
    private Vector3 ultimaPosicaoVista;

    void Update()
    {
        bool viu = EnxergaAlvo();
        float distancia = Vector3.Distance(transform.position, alvo.position);

        if (viu)
        {
            tempoSemVer = 0f;
            ultimaPosicaoVista = alvo.position;   // só o que foi visto é conhecido
        }
        else tempoSemVer += Time.deltaTime;

        // Árvore de decisão: a ordem das perguntas define a personalidade
        if (viu && distancia <= alcanceAtaque) estado = Estado.Atacar;
        else if (viu) estado = Estado.Perseguir;
        else if (estado != Estado.Patrulha && tempoSemVer > tempoParaDesistir) estado = Estado.Patrulha;

        switch (estado)
        {
            case Estado.Patrulha:  Patrulhar(); break;
            case Estado.Perseguir: Mover(ultimaPosicaoVista, velocidadePerseguicao); break;
            case Estado.Atacar:    Atacar(); break;
        }
    }

    private bool EnxergaAlvo()
    {
        Vector3 ate = alvo.position - transform.position;
        if (ate.magnitude > alcanceVisao) return false;
        if (Vector3.Angle(transform.forward, ate) > anguloVisao * 0.5f) return false;

        // Raycast à altura dos olhos: uma parede no caminho bloqueia a visão
        Vector3 olhos = transform.position + Vector3.up;
        Vector3 destino = alvo.position + Vector3.up;
        return !Physics.Linecast(olhos, destino, obstaculos);
    }

    private void Patrulhar()
    {
        if (pontosDePatrulha == null || pontosDePatrulha.Length == 0) return;

        Transform ponto = pontosDePatrulha[pontoAtual];
        Mover(ponto.position, velocidadePatrulha);

        Vector3 plano = ponto.position - transform.position; plano.y = 0f;
        if (plano.magnitude < 0.3f) pontoAtual = (pontoAtual + 1) % pontosDePatrulha.Length;
    }

    private void Mover(Vector3 destino, float velocidade)
    {
        Vector3 direcao = destino - transform.position; direcao.y = 0f;
        if (direcao.sqrMagnitude < 0.0001f) return;

        transform.position += direcao.normalized * velocidade * Time.deltaTime;
        transform.rotation = Quaternion.Slerp(transform.rotation,
            Quaternion.LookRotation(direcao), 8f * Time.deltaTime);
    }

    private void Atacar()
    {
        if (Time.time < proximoAtaque) return;

        if (alvo.TryGetComponent(out IDanificavel vitima))
        {
            vitima.ReceberDano(dano);
            proximoAtaque = Time.time + intervaloAtaque;
        }
    }
}

Quatro detalhes importantes: o inimigo persegue a última posição em que viu o herói, e não a posição real, o que torna possível se esconder (do contrário ele seria onisciente); o ângulo de visão impede o inimigo de enxergar às costas; o Linecast impede de enxergar através de paredes; e o tempoParaDesistir dá ao jogador a chance de fugir, o que torna o stealth possível.

Montando a sala de teste

Crie o posto de guarda

Em uma sala do seu cenário, crie três objetos vazios (Ponto A, Ponto B, Ponto C) em triângulo no chão. Eles são a rota da patrulha.

Prepare o inimigo

Use um modelo de monstro (o do kit ou o seu) e adicione InimigoIA. O jogador precisa ter o componente Vida do módulo 6, pois é por ele que o dano chega. Arraste o jogador para Alvo, os três pontos para Pontos de Patrulha e marque a camada das paredes em Obstaculos.

Desenhe o campo de visão

Adicione ao script um método OnDrawGizmosSelected que desenha uma esfera de alcance e duas linhas nos limites do ângulo. Ver a visão na aba Scene acelera todo o ajuste.

Teste os quatro comportamentos

Aperte Play e confira: ele patrulha; vê você de frente e persegue; perde você atrás de uma parede e, depois de 3 s, volta à patrulha; encostado em você, ataca.

Checkpoint: o inimigo muda de estado conforme sua posição, não enxerga através de paredes e retorna à patrulha quando você some.

IA que o jogador entende

IA de jogo não é inteligência: é legibilidade. O jogador precisa perceber o que o inimigo está fazendo para poder reagir. Algumas técnicas baratas:

TécnicaEfeito
Cor ou ícone acima da cabeçaMostra o estado atual (calmo, alerta, perseguindo)
Som ao mudar de estadoAvisa o jogador de que foi visto
Atraso de reação (0,3 s)Faz o inimigo parecer humano e dá chance de escapar
Velocidade menor que a do herói na perseguiçãoTorna a fuga possível; a tensão vem do risco, não da injustiça
Conexão com as mecânicas. Stealth usa visão e som; Survival usa perseguição e desistência; Corrida usa adversários que seguem pontos de uma pista; Plataforma usa patrulha entre bordas; Puzzle usa inimigos de rota fixa que o jogador precisa estudar.

Checkpoint do módulo

  • pelo menos um inimigo com máquina de estados de 3 ou mais estados, com os valores ajustáveis no Inspector;
  • percepção por distância e ângulo e, quando fizer sentido, bloqueio por obstáculos;
  • um Gizmo mostrando o alcance de visão na aba Scene;
  • uma indicação visual ou sonora do estado do inimigo;
  • o diagrama de estados do inimigo desenhado e anexado ao repositório.

Problemas comuns

O inimigo me vê através da parede

O campo Obstaculos está vazio ou a parede está em outra camada. Marque a camada correta e confirme que a parede tem colisor.

O inimigo anda afundando ou voando

O código zera o eixo Y da direção, então a altura nunca muda. Se o chão for irregular, use CharacterController ou NavMeshAgent (próximo módulo).

Ele fica tremendo ao chegar no ponto de patrulha

A tolerância de chegada (0,3) está pequena demais para a velocidade. Aumente-a ou reduza a velocidade perto do destino.

Ele nunca desiste da perseguição

Se o jogador continua dentro do campo de visão, o contador zera sempre. Teste escondendo-se atrás de um obstáculo ou fora do ângulo de visão.
