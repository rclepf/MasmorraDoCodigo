Importando sem retrabalho

Escolha o formato

Para modelos do Blender, exporte em FBX (Atividade 12). A Unity também aceita OBJ, como no kit. Mantenha uma pasta por tipo: Models, Textures, Materials, Audio, Sprites.

Confira o Inspector do modelo

Aba Model: Scale Factor deve resultar em tamanho real (1 unidade = 1 metro). Aba Rig: para personagens humanoides, use Humanoid; para os demais, Generic. Aba Materials: use Extract Materials para editar os materiais fora do modelo.

Importe texturas com o tipo certo

Selecione cada imagem e ajuste Texture Type: Default para Albedo, Normal map para normais. Para pixel art, use Sprite (2D and UI), Filter Mode: Point (no filter) e Compression: None, ou ela fica borrada.

Monte o prefab

Arraste o modelo para a cena, ajuste materiais e componentes e arraste para Assets/Prefabs. A partir daqui, use sempre o prefab.

Este é o mesmo cuidado de nomes e organização da Atividade 11. Um projeto bagunçado vira horas perdidas procurando arquivos.

Animando o herói

O Animator é uma máquina de estados: cada estado é uma animação (parado, andando, atacando) e as transições entre eles dependem de parâmetros que o código atualiza.

Crie o Animator Controller

Em Assets/Animations, crie um Animator Controller chamado Heroi. Abra a aba Animator, crie os estados Parado e Andando arrastando os clipes de animação do seu rig e adicione o parâmetro Velocidade do tipo Float.

Crie as transições

De Parado para Andando: condição Velocidade Greater 0.1. De Andando para Parado: Velocidade Less 0.1. Desligue Has Exit Time em ambas, para a troca ser imediata.

Conecte ao código

Anexe o script abaixo ao objeto do modelo (o filho com o componente Animator).

AnimadorJogador.cs 
using UnityEngine;

public class AnimadorJogador : MonoBehaviour
{
    [SerializeField] private CharacterController controle;
    [SerializeField] private float suavizacao = 10f;

    private Animator animator;
    private float velocidadeSuavizada;
    private static readonly int Velocidade = Animator.StringToHash("Velocidade");

    void Awake() => animator = GetComponent<Animator>();

    void Update()
    {
        // Velocidade horizontal real do personagem, ignorando a queda
        Vector3 horizontal = new Vector3(controle.velocity.x, 0f, controle.velocity.z);
        velocidadeSuavizada = Mathf.Lerp(velocidadeSuavizada, horizontal.magnitude, suavizacao * Time.deltaTime);
        animator.SetFloat(Velocidade, velocidadeSuavizada);
    }
}

Animator.StringToHash converte o nome do parâmetro em um número uma única vez, o que é mais rápido do que procurar o texto a cada quadro.

Se você não tem animações

O herói e os inimigos do kit são modelos rígidos, sem esqueleto. Para eles ganharem vida, anime por código:

BalancoVisual.cs 
using UnityEngine;

public class BalancoVisual : MonoBehaviour
{
    [SerializeField] private float amplitude = 0.08f;
    [SerializeField] private float frequencia = 4f;
    [SerializeField] private float respiro = 0.03f;

    private Vector3 posicaoInicial;
    private Vector3 escalaInicial;

    void Start()
    {
        posicaoInicial = transform.localPosition;
        escalaInicial = transform.localScale;
    }

    void Update()
    {
        float onda = Mathf.Sin(Time.time * frequencia);
        transform.localPosition = posicaoInicial + Vector3.up * (onda * amplitude);
        transform.localScale = escalaInicial * (1f + onda * respiro);
    }
}

Coloque este script no modelo, que é filho do objeto de gameplay, e não no objeto raiz: assim o balanço não interfere no movimento nem nos colisores.

Acendendo a masmorra

Luz é parte de gameplay: ela guia o olhar do jogador e cria clima. Uma sala escura com tochas acesas conta uma história sem texto.

Reduza a luz geral

Em Window > Rendering > Lighting, escureça o Environment (Intensity Multiplier em 0.2). Diminua a intensidade da Directional Light.

Adicione luzes às tochas

Dentro do prefab Torch, crie uma Point Light alaranjada logo acima da chama, com alcance de 6 a 8 metros e coloque o script abaixo.

LuzTocha.cs 
using UnityEngine;

[RequireComponent(typeof(Light))]
public class LuzTocha : MonoBehaviour
{
    [SerializeField] private float intensidadeBase = 2.5f;
    [SerializeField] private float variacao = 0.6f;
    [SerializeField] private float velocidade = 3f;

    private Light luz;
    private float semente;

    void Awake()
    {
        luz = GetComponent<Light>();
        semente = Random.value * 100f;   // cada tocha com ritmo próprio
    }

    void Update()
    {
        float ruido = Mathf.PerlinNoise(semente, Time.time * velocidade);
        luz.intensity = intensidadeBase + (ruido - 0.5f) * 2f * variacao;
    }
}

Ruído de Perlin gera variações suaves e aleatórias, bem mais naturais que Random.Range a cada quadro, que daria um pisca-pisca nervoso.

Interface e identidade visual

Crie o Canvas

Em GameObject > UI > Canvas. Ajuste UI Scale Mode para Scale With Screen Size e resolução de referência 1920 por 1080.

Coloque o logotipo

Importe o PNG do logotipo (Atividade 01, exportado com fundo transparente) como Sprite (2D and UI) e arraste para o Canvas como Image. Ancore no topo, centralizado.

Crie o contador de moedas

Adicione um TextMeshPro - Text no canto superior direito com o ícone de moeda em pixel art ao lado. O script do próximo módulo vai atualizá-lo.

Âncoras são o segredo da UI: um elemento ancorado no canto continua no canto em qualquer resolução. Teste na aba Game trocando a proporção da tela.

Colocando som no jogo

Dois componentes bastam: o AudioSource toca sons e o AudioListener (já presente na câmera) escuta. Para efeitos curtos, use PlayOneShot, que permite sobrepor vários sons sem cortar o anterior.

SomColeta.cs 
using UnityEngine;

[RequireComponent(typeof(AudioSource))]
public class SomColeta : MonoBehaviour
{
    [SerializeField] private AudioClip somMoeda;
    [SerializeField] private AudioClip somChave;
    [SerializeField, Range(0f, 1f)] private float volume = 0.8f;

    private AudioSource fonte;

    void Awake() => fonte = GetComponent<AudioSource>();

    public void Tocar(Coletavel.Tipo tipo)
    {
        AudioClip clipe = tipo == Coletavel.Tipo.Moeda ? somMoeda : somChave;
        if (clipe != null) fonte.PlayOneShot(clipe, volume);
    }
}

Anexe ao Jogador e, no Inventario do módulo 3, chame GetComponent<SomColeta>()?.Tocar(tipo) dentro de Adicionar. Para trilha ambiente, crie um AudioSource com Loop ligado e Spatial Blend em 0.

Use os sons que você editou e mixou na UC anterior. Prefira WAV para efeitos curtos e OGG para trilhas longas.

Checkpoint: o herói anda animado, as tochas piscam, o logotipo e o contador aparecem na tela e coletar uma moeda toca um som.

Checkpoint do módulo

  • pelo menos 3 assets seus ou do kit importados com escala, materiais e tipo de textura corretos;
  • personagem com Animator (ou balanço procedural) respondendo à velocidade;
  • iluminação intencional, com ao menos 2 fontes de luz de cena;
  • interface com logotipo e um indicador de jogo;
  • 3 sons integrados e disparados por código.

As instruções completas estão na Atividade Prática C04.

Problemas comuns

O personagem faz a animação mas desliza pelo chão

A velocidade do clipe não combina com a do movimento. Ajuste Speed do estado ou a velocidade do script até os pés não escorregarem.

O sprite de pixel art aparece borrado

Troque Filter Mode para Point (no filter) e Compression para None nas configurações da imagem.

Os materiais do modelo aparecem rosa

O shader não é compatível com o pipeline de render do projeto. Use Edit > Rendering > Materials > Convert Built-in Materials to URP ou recrie com o shader Lit.

Não ouço nada ao coletar

Verifique se os clipes foram arrastados no Inspector, se a câmera tem AudioListener e se o volume do jogo (ícone de alto-falante na aba Game) não está mudo.

O Animator não muda de estado

Confira o nome exato do parâmetro (Velocidade) no controlador e no script, e se o componente Animator tem o controlador atribuído.
