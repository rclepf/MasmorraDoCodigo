Ligação com a UC anterior

O herói que você vai mover pode ser o seu personagem do Blender, com a escala e a origem corrigidas nas Atividades 11 e 12. Quem não tiver um personagem usa o Player do kit, que tem cerca de 2 metros de altura.

Origem do modelo importa. Se o ponto de origem do seu modelo estiver no centro do corpo e não nos pés, ele vai afundar ou flutuar no chão. Corrija no Blender com Set Origin e exporte de novo.

Como a Unity entende o espaço 3D

A Unity usa o eixo Y para cima, Z para frente e X para a direita. É um sistema de coordenadas diferente do Blender, que usa Z para cima. O importador converte isso na maioria dos casos, mas é a origem de modelos "deitados".

ConceitoO que éExemplo
Vector3Três números (x, y, z) que representam posição, direção ou velocidadenew Vector3(0, 0, 1) aponta para frente
TransformPosição, rotação e escala de todo objetotransform.position
Espaço local x mundialLocal é relativo ao objeto pai; mundial é relativo à cenatransform.forward é a frente local em coordenadas do mundo
Time.deltaTimeSegundos desde o quadro anteriorMultiplique por ele para o movimento não depender da taxa de quadros

Sem Time.deltaTime, um jogo a 120 quadros por segundo moveria o herói duas vezes mais rápido que a 60. Esse é um erro clássico em jogos.

Lendo teclado e controle

A Unity moderna usa o pacote Input System. Em projetos novos ele já vem instalado. Confira em Window > Package Manager > In Project. Se o projeto estiver usando o sistema antigo, vá em Edit > Project Settings > Player > Active Input Handling e selecione Input System Package (New) ou Both.

Uma InputAction descreve uma ação do jogador ("mover") e quais controles a disparam. Nesta aula ela é criada por código, para você enxergar tudo em um só arquivo:

trecho: criando a ação de movimento 
InputAction mover = new InputAction("Mover", InputActionType.Value);
mover.AddCompositeBinding("2DVector")
     .With("Up", "<Keyboard>/w").With("Down", "<Keyboard>/s")
     .With("Left", "<Keyboard>/a").With("Right", "<Keyboard>/d");
mover.AddBinding("<Gamepad>/leftStick");

O resultado de mover.ReadValue<Vector2>() é um vetor com valores de -1 a 1: W e S alteram o Y, A e D alteram o X. O mesmo código aceita o analógico esquerdo do controle.

O script de movimento

Monte o herói

Crie um objeto vazio chamado Jogador na posição (0, 0, 0) e coloque o modelo do herói como filho dele. Adicione ao Jogador o componente CharacterController com Height 2, Radius 0.35 e Center (0, 1, 0). Coloque a tag Player no objeto.

Crie o script

Em Assets/Scripts, crie PlayerMovement, anexe ao Jogador e cole o código abaixo.

PlayerMovement.cs 
using UnityEngine;
using UnityEngine.InputSystem;

[RequireComponent(typeof(CharacterController))]
public class PlayerMovement : MonoBehaviour
{
    [SerializeField] private float velocidade = 5f;
    [SerializeField] private float suavizacaoGiro = 12f;
    [SerializeField] private float gravidade = -20f;

    private CharacterController controle;
    private Transform cam;
    private InputAction mover;
    private float velocidadeVertical;

    void Awake()
    {
        controle = GetComponent<CharacterController>();
        cam = Camera.main.transform;

        mover = new InputAction("Mover", InputActionType.Value);
        mover.AddCompositeBinding("2DVector")
             .With("Up", "<Keyboard>/w").With("Down", "<Keyboard>/s")
             .With("Left", "<Keyboard>/a").With("Right", "<Keyboard>/d");
        mover.AddBinding("<Gamepad>/leftStick");
    }

    void OnEnable() => mover.Enable();
    void OnDisable() => mover.Disable();

    void Update()
    {
        Vector2 entrada = mover.ReadValue<Vector2>();

        // Direções da câmera projetadas no chão: W anda para onde a câmera olha
        Vector3 frente = Vector3.ProjectOnPlane(cam.forward, Vector3.up).normalized;
        Vector3 direita = Vector3.ProjectOnPlane(cam.right, Vector3.up).normalized;
        Vector3 direcao = Vector3.ClampMagnitude(frente * entrada.y + direita * entrada.x, 1f);

        // Gravidade simples
        if (controle.isGrounded && velocidadeVertical < 0f) velocidadeVertical = -2f;
        velocidadeVertical += gravidade * Time.deltaTime;

        Vector3 movimento = direcao * velocidade + Vector3.up * velocidadeVertical;
        controle.Move(movimento * Time.deltaTime);

        // Gira suavemente para a direção do movimento
        if (direcao.sqrMagnitude > 0.01f)
        {
            Quaternion alvo = Quaternion.LookRotation(direcao);
            transform.rotation = Quaternion.Slerp(transform.rotation, alvo, suavizacaoGiro * Time.deltaTime);
        }
    }
}

Vector3.ClampMagnitude impede que andar na diagonal seja mais rápido: sem ele, W + D produz um vetor de comprimento 1,41. O -2f mantém o herói colado ao chão em rampas e degraus.

Câmera que acompanha o herói

Câmeras devem se mover depois do personagem, no mesmo quadro. Por isso o código usa LateUpdate, que roda depois de todos os Update. Se a câmera for atualizada antes, a imagem treme.

CameraSeguir.cs 
using UnityEngine;

public class CameraSeguir : MonoBehaviour
{
    [SerializeField] private Transform alvo;
    [SerializeField] private Vector3 deslocamento = new Vector3(0f, 6f, -7f);
    [SerializeField] private float suavizacao = 8f;
    [SerializeField] private float alturaDoOlhar = 1.5f;

    void LateUpdate()
    {
        if (alvo == null) return;

        Vector3 desejada = alvo.position + deslocamento;
        transform.position = Vector3.Lerp(transform.position, desejada, suavizacao * Time.deltaTime);
        transform.LookAt(alvo.position + Vector3.up * alturaDoOlhar);
    }
}

Anexe e configure

Anexe o script à Main Camera e arraste o Jogador para o campo Alvo. Aperte Play e ande pela sala. Ajuste deslocamento no Inspector enquanto o jogo roda para achar o enquadramento que você prefere. Valores alterados no Play Mode voltam ao normal ao parar: anote os bons.

Teste os limites

Tente andar na diagonal, soltar as teclas e mudar rápido de direção. Observe se o giro está brusco ou lento demais e ajuste suavizacaoGiro.

Checkpoint: o herói anda em qualquer direção relativa à câmera, gira suavemente, não atravessa o chão e a câmera o acompanha sem tremer.

Enxergando o que o código calcula

Valores como direção e velocidade são invisíveis. Para depurar movimento, desenhe-os na cena. Acrescente este método ao PlayerMovement:

trecho: dentro de PlayerMovement 
void OnDrawGizmosSelected()
{
    Gizmos.color = Color.cyan;
    Gizmos.DrawRay(transform.position + Vector3.up, transform.forward * 2f);
}

Com o Jogador selecionado, a aba Scene mostra uma linha ciano para onde ele está virado. Para valores que mudam a cada quadro, use Debug.DrawRay dentro do Update e olhe a Scene durante o Play.

Problemas comuns

Mensagem de erro sobre Input ou InputSystem no Console

Falta o pacote Input System ou o Active Input Handling está em Input Manager (Old). Instale o pacote, ajuste a configuração e reinicie a Unity quando ela pedir.

O herói cai pelo chão

O piso não tem colisor. Selecione o modelo do piso, na aba Model marque Generate Colliders e clique em Apply, ou adicione um Box Collider ao objeto.

A câmera treme quando ando

A câmera está sendo movida em Update. Mova em LateUpdate, como no script.

O herói anda muito rápido ou muito devagar

Confira se o movimento está multiplicado por Time.deltaTime e ajuste velocidade no Inspector, não no código.

O herói gira para o lado errado ao andar

O modelo foi exportado do Blender com o eixo da frente errado. No Blender, a frente do modelo deve apontar para -Y e a exportação FBX deve usar Forward = -Z, Up = Y. Corrija e importe de novo.
