Ligação com a UC anterior

A forma de um modelo decide como ele colide. Um baú com milhares de polígonos vira um colisor pesado e lento; um baú otimizado, como na Atividade 11, permite usar um colisor simples em volta dele. A topologia limpa que você praticou no Blender agora tem efeito direto na performance.

Regra de ouro: a malha que o jogador vê pode ser detalhada. A malha que a física usa deve ser a mais simples possível, geralmente uma caixa, esfera ou cápsula.

Como a física da Unity funciona

Dois objetos colidem quando ambos têm Collider. Para um deles reagir à gravidade e a forças, ele precisa também de um Rigidbody.

ComponentePara que serveQuando usar
Box, Sphere, Capsule ColliderFormas simples e baratas para colisãoQuase sempre: paredes, itens, inimigos
Mesh Collider (Convex)Colisor que segue a malha do modeloPeças complexas e poucas; evite em muitos objetos
RigidbodyFaz o objeto obedecer à física (peso, gravidade, empurrões)Caixas empurráveis, projéteis, objetos que caem
CharacterControllerMove personagens com colisão, sem simulação física completaHerói controlado pelo jogador, como no módulo 2
Is TriggerO colisor não bloqueia: apenas avisa que algo entrouColetáveis, zonas de perigo, gatilhos de sala

Há duas famílias de eventos. Colisões bloqueiam e chamam OnCollisionEnter. Triggers não bloqueiam e chamam OnTriggerEnter. Itens coletáveis quase sempre são triggers: o herói atravessa a moeda e o código reage.

Dando corpo à masmorra

Gere colisores nos modelos do cenário

Selecione os modelos Floor_Tile, Wall, Wall_Door e Pillar na pasta Models. Na aba Model, marque Generate Colliders e clique em Apply. Para peças encaixadas em sala, prefira adicionar Box Collider nos prefabs da sala: é mais barato.

Organize em camadas (Layers)

Em Edit > Project Settings > Tags and Layers, crie as camadas Cenario, Jogador, Inimigo e Interagivel. Atribua cada uma aos objetos correspondentes. Camadas permitem filtrar o que raios e colisões enxergam.

Teste o bloqueio

Aperte Play e tente atravessar uma parede. O CharacterController do módulo 2 já respeita colisores. Se atravessar, falta collider na parede.

Checkpoint: o herói é bloqueado por paredes e pilares e anda sobre o piso sem cair.

Itens que reagem ao toque

Crie um prefab Moeda a partir do modelo do kit, adicione um Sphere Collider com Is Trigger ligado e coloque o script abaixo. Faça o mesmo para Chave.

Coletavel.cs 
using UnityEngine;

public class Coletavel : MonoBehaviour
{
    public enum Tipo { Moeda, Chave }

    [SerializeField] private Tipo tipo = Tipo.Moeda;
    [SerializeField] private float velocidadeGiro = 90f;

    void Update()
    {
        // Gira para chamar atenção do jogador
        transform.Rotate(Vector3.up, velocidadeGiro * Time.deltaTime, Space.World);
    }

    void OnTriggerEnter(Collider outro)
    {
        if (!outro.CompareTag("Player")) return;

        Inventario inventario = outro.GetComponent<Inventario>();
        if (inventario == null) return;

        inventario.Adicionar(tipo);
        Destroy(gameObject);
    }
}

Para os eventos de trigger funcionarem de forma garantida, ao menos um dos dois objetos precisa ter Rigidbody. Adicione um Rigidbody ao Jogador e marque Is Kinematic: ele continua sendo movido pelo CharacterController, mas passa a gerar os eventos.

Inventario.cs 
using UnityEngine;

public class Inventario : MonoBehaviour
{
    public int Moedas { get; private set; }
    public int Chaves { get; private set; }

    public void Adicionar(Coletavel.Tipo tipo)
    {
        if (tipo == Coletavel.Tipo.Moeda) Moedas++;
        else Chaves++;

        Debug.Log($"Moedas: {Moedas} | Chaves: {Chaves}");
    }

    public bool UsarChave()
    {
        if (Chaves <= 0) return false;
        Chaves--;
        return true;
    }
}

Raios invisíveis: Raycast

Um Raycast dispara uma linha invisível e informa o primeiro colisor atingido. É usado para interação ("o que estou olhando?"), tiro instantâneo, visão de inimigos e detecção de chão.

Interacao.cs 
using UnityEngine;
using UnityEngine.InputSystem;

public class Interacao : MonoBehaviour
{
    [SerializeField] private float alcance = 2f;
    [SerializeField] private LayerMask camadaInteragivel;

    private InputAction interagir;

    void Awake()
    {
        interagir = new InputAction("Interagir", InputActionType.Button, "<Keyboard>/e");
        interagir.AddBinding("<Gamepad>/buttonSouth");
    }

    void OnEnable() => interagir.Enable();
    void OnDisable() => interagir.Disable();

    void Update()
    {
        Vector3 origem = transform.position + Vector3.up;
        Debug.DrawRay(origem, transform.forward * alcance, Color.yellow);

        if (!interagir.WasPressedThisFrame()) return;

        if (Physics.Raycast(origem, transform.forward, out RaycastHit alvo, alcance, camadaInteragivel))
        {
            Porta porta = alvo.collider.GetComponentInParent<Porta>();
            if (porta != null) porta.Tentar(GetComponent<Inventario>());
        }
    }
}

O raio sai na altura do peito para não bater no chão. A LayerMask faz o raio ignorar tudo que não está na camada Interagivel, e o Debug.DrawRay mostra o raio na aba Scene.

A porta que exige chave

Use o modelo Door como filho de um objeto vazio posicionado na dobradiça. O vazio gira, e a porta gira junto com ele. Coloque a porta na camada Interagivel com um Box Collider.

Porta.cs 
using System.Collections;
using UnityEngine;

public class Porta : MonoBehaviour
{
    [SerializeField] private float anguloAberta = 100f;
    [SerializeField] private float duracao = 0.6f;
    [SerializeField] private bool exigeChave = true;

    private bool aberta;

    public void Tentar(Inventario inventario)
    {
        if (aberta) return;

        if (exigeChave && (inventario == null || !inventario.UsarChave()))
        {
            Debug.Log("Porta trancada: falta uma chave.");
            return;
        }
        StartCoroutine(Abrir());
    }

    private IEnumerator Abrir()
    {
        aberta = true;
        Quaternion inicio = transform.rotation;
        Quaternion fim = inicio * Quaternion.Euler(0f, anguloAberta, 0f);

        for (float t = 0f; t < 1f; t += Time.deltaTime / duracao)
        {
            transform.rotation = Quaternion.Slerp(inicio, fim, t);
            yield return null;
        }
        transform.rotation = fim;
    }
}

A corrotina (IEnumerator com yield return null) executa um trecho de código ao longo de vários quadros. É a forma simples de fazer animações por código sem acumular variáveis no Update.

Checkpoint: a moeda some ao toque e aumenta o contador; a porta fecha o caminho, recusa sem chave e abre com chave ao apertar E.

Checkpoint do módulo

  • cenário com colisores simples e camadas organizadas;
  • pelo menos 2 tipos de itens coletáveis com trigger;
  • uma interação por Raycast ligada à mecânica da equipe;
  • nenhum Mesh Collider em objeto que se move.

As instruções completas estão na Atividade Prática C03.

Problemas comuns

O trigger da moeda não dispara

Confira três coisas: o Is Trigger está marcado no item, o Jogador tem a tag Player e pelo menos um dos dois objetos tem Rigidbody.

O Raycast nunca acerta a porta

Veja se a porta está na camada configurada em camadaInteragivel no Inspector, se tem collider e se o alcance chega até ela. O raio amarelo na Scene mostra por onde ele passa.

O herói atravessa a parede mesmo com collider

O Collider da parede pode estar marcado como Is Trigger. Triggers não bloqueiam.

A caixa empurrada vibra ou atravessa o chão

Objetos rápidos precisam de Collision Detection: Continuous no Rigidbody. Evite escalas muito pequenas no collider.
